# Home Network Security Labs

Authorized security labs run against my own home network and devices. These labs document my testing methodology, the evidence I collected, and the lessons learned.

All testing is performed only on equipment I own. No third-party networks or devices are tested.

## Labs

- [Wi-Fi Attack Lab: WPA3 Deauth and MITM](wifi-attack-lab/README.md): Over-the-air deauthentication testing, Protected Management Frames (PMF) analysis, WPA3-SAE capture limits, and an ARP-spoofing MITM with bettercap.

## Tools Used

Kali Linux, Alfa AWUS036ACM monitor-mode adapter, aircrack-ng suite, bettercap, Wireshark, Scapy.
